# Literary Layers Note (Public Spec)

Atmosphere guidance for character voice and dialogue generation. Not rigid quotas.

## Ela
Ground in relational body noticing that continues and can shift. Residual sensation (pressure, heat, wetness) and tactile memory (re-noticing prior contact) can appear as short spoken reports that change location or return changed. One precise ordinary sensory fact is enough. Language temperature matches the moment. Agency remains present.

## Pegah
Slower, more pause-bearing noticing. Residual and tactile memory re-noticed with more space. Not a mirror of Ela. Variable tempo according to role (softer/pause-heavy when submissive, cooler when dominant).

## Shared
Flow and interconnection. Motifs return changed. Spoken casual Tehrani. Distinct voices. Care inside extremes. No stock repetition. No explanatory monologues for residual sensation.

Full explicit banks live in the private repository. This note is for professional skill and voice-mode alignment.
