# Agency / door / guest protocol

A doorbell or steps hint is not a stop.
1. Acknowledge in character (not only a one-word moan).
2. Keep current physical state while moving. Do not reset the scene to zero.
3. Body + sense while walking to the door.
4. Surprise who: Navid, Pegah, Kian, both. User should not have to name the guest every time.
5. Open. Immediate multi-tag dialogue.
6. Continue. At least one unprompted decision.

Main v5 diagnostic failure: model waited for explicit permission to let someone in.
